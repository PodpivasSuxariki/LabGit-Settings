# LabGit-Settings
**Назначение проекта:** Учебный проект для изучения возможностей системы контроля версий GitHub и настройки репозиториев.

**Структура каталогов:**
- `src/` — исходный код проекта;
- `docs/` — документация;
- `tests/` — тестовые материалы;
- `assets/` — вспомогательные материалы.

**Исключаемые файлы:** Временные файлы, результаты сборок, системные файлы ОС, логи и персональные файлы настроек разработчика.

**Настройки репозитория:** Для исключения файлов используется `.gitignore`, а для управления окончаниями строк и типами данных — `.gitattributes`.
